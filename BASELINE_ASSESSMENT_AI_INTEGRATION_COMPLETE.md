## Technical Architecture

### Multi-Provider AI System
```
Frontend Request
     ↓
BaselineAPI.startSession()
     ↓
FastAPI Backend (/api/v1/baseline/start-session)
     ↓
AI Provider Chain:
  1. Try OpenAI (gpt-4)
  2. Fallback to Anthropic (claude-3)
  3. Fallback to Google Gemini
  4. Fallback to Mock (dev/testing)
     ↓
IRT-Based Item Selection
     ↓
Return AI-Generated Question
     ↓
Frontend Displays Question
```

### Response Flow
```
User Submits Answer
     ↓
handleItemSubmit()
     ↓
BaselineAPI.submitResponse() with engagement metrics
     ↓
Backend Scores Response
     ↓
Backend Updates IRT Theta/SE
     ↓
Backend Generates Next Question (AI)
     ↓
Frontend Receives Next Item
     ↓
Display Next Question
```

## API Endpoints Used

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/v1/baseline/start-session` | POST | Initialize assessment, get first question |
| `/api/v1/baseline/submit-response` | POST | Submit answer, get next question |
| `/api/v1/baseline/session-status` | GET | Check current session state |
| `/api/v1/baseline/pause` | POST | Pause assessment |
| `/api/v1/baseline/resume` | POST | Resume assessment |
| `/api/v1/baseline/start-break` | POST | Begin break period |
| `/api/v1/baseline/end-break` | POST | End break period |
| `/api/v1/baseline/results/{session_id}` | GET | Get final results |
