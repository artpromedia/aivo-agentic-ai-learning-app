# Focus Monitor Quick Reference 🎯

## How It Works

### 1. Automatic Tracking
The Focus Monitor runs in the background, tracking:
- ⏱️ **Time on Task**: How long you've been learning
- 🎯 **Answer Streaks**: Correct answers in a row
- 😴 **Idle Time**: Time since last interaction
- 📊 **Attention Score**: 0-100% based on all metrics

### 2. Focus States

| State | Score | Indicator | Meaning |
|-------|-------|-----------|---------|
| 🎯 **Focused** | 70-100% | Green | Optimal learning state |
| 💭 **Wandering** | 40-69% | Yellow | Attention drifting |
| 😵 **Distracted** | 0-39% | Red | Need a break |

### 3. Game Breaks

**Daily Limit**: 3 breaks per day

**When Suggested**:
- Attention score below 70%
- Multiple wrong answers
- Extended idle time

**How to Use**:
1. See blue suggestion alert
2. Click "Start Game Break"
3. Choose a game:
   - 🎮 **Simon Says** (60s) - Memory patterns
   - 🃏 **Memory Match** (90s) - Card matching
   - 🧘 **Breathing** (60s) - Calm meditation
4. Play the game
5. Return refreshed to lesson

**Manual Breaks**:
- Click "Start Break" anytime
- Still counts toward daily limit
- Available while breaks remaining

## Mini-Games

### 🎮 Simon Says
- Watch color pattern
- Repeat the pattern
- Pattern grows each round
- Score: Rounds completed

### 🃏 Memory Match
- Flip 2 cards at a time
- Find all 8 matching pairs
- Score: Matches × 10 + Time Bonus

### 🧘 Breathing Exercise
- Follow the circle
- Inhale (4s): Blue circle expands
- Hold (4s): Purple circle stays
- Exhale (4s): Green circle contracts
- Score: Cycles × 10

## Tips for Best Focus

✅ **Do**:
- Stay active (click, scroll, answer)
- Take breaks when suggested
- Use breathing exercise for stress
- Keep correct answer streaks

❌ **Don't**:
- Idle for long periods
- Rush through questions
- Ignore break suggestions
- Use all breaks early in session

## Troubleshooting

**Q: Attention score keeps dropping?**  
A: Stay active! Move mouse, answer questions, scroll. The system detects activity.

**Q: No breaks left but still distracted?**  
A: Try manual techniques: stretch, deep breaths, quick walk. Come back when ready.

**Q: Games not working?**  
A: Ensure JavaScript enabled. Try refreshing page. Check browser console for errors.

**Q: Want more breaks?**  
A: 3 per day prevents excessive gaming. Designed for optimal learning, not unlimited play.
